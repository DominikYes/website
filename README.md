# Orbit Chat UI

Static iOS 26-inspired AI chat app mockup.

## Run locally

```bash
python -m http.server 8000
```

Open `http://127.0.0.1:8000` in your browser.

## Deploy

This project includes a `netlify.toml` that publishes the repository root and
redirects all routes to `index.html` to prevent “not found” errors for deep
links.
